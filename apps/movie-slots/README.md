# 🎰 Sharelies Movie Pokie

Pull the lever, spin the theatre marquee, land tonight's movie. Never one we've already watched.

What it does and why: [`SPEC.md`](SPEC.md). Its look lives in `src/theme.css`.
Add or edit movies in [`src/data/movies.json`](src/data/movies.json) (`title`, `year`, `category`).

```bash
npm run dev -w apps/movie-slots
```
