# 🏡 Sharelies apps

Fun little apps for the Sharelies sharehouse, all in one place.

**Open them:** https://clany97.github.io/Sharelies-apps/

## Ask for an app

1. Open a new issue and pick **💡 App idea** (or **✏️ Change to an app**).
2. Lachie adds the `factory:build` label.
3. A coding agent plans it, builds it, checks it, and opens a pull request.
4. Lachie tries it and merges. It's live a couple of minutes later.

How the factory works: [`docs/factory.md`](docs/factory.md).
How the repo is laid out and why: [`docs/architecture.md`](docs/architecture.md).

## Work on it locally

```bash
npm install
npm run dev -w apps/hub
```

Rules for people and agents: [`AGENTS.md`](AGENTS.md) (works with any coding agent).
